# Changelog

Все значимые изменения в проекте Smart Areometr документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] - 2025-12-17

### 🎉 Основные изменения

#### Переход на поддерживаемый форк ESPAsyncWebServer
- **Критическое исправление:** Заменена библиотека `ESPAsyncWebServer-esphome` на поддерживаемый форк `ESP32Async/ESPAsyncWebServer`
- **Решение проблемы паник:** Исправлена ошибка "Guru Meditation Error: Load access fault" на ESP32-C3
- **Совместимость:** Улучшена стабильность веб-сервера на ESP32-C3

#### Технические улучшения
- Обновлены все обработчики веб-сервера на синтаксис AsyncWebServer с `AsyncWebServerRequest`
- Добавлен флаг компиляции `-fpermissive` для разрешения проблем совместимости
- Увеличен размер стека AsyncTCP до 16384 байт для стабильной работы
- Убраны ненужные вспомогательные функции

#### Документация
- Обновлена документация с информацией о решении проблем веб-сервера
- Добавлены инструкции по устранению паник в `TROUBLESHOOTING.md`
- Обновлен `ESP32-C3_COMPILATION_FIXES.md` с информацией о веб-сервере
- Обновлен `INTEGRATION_ROADMAP.md` с правильными зависимостями

### 🔧 Изменения в зависимостях

**platformio.ini:**
```ini
lib_deps =
    # Заменено:
    # ottowinter/ESPAsyncWebServer-esphome@^3.1.0
    # На:
    https://github.com/ESP32Async/ESPAsyncWebServer.git
    me-no-dev/AsyncTCP@^1.1.1
```

**build_flags:**
```ini
build_flags =
    -fpermissive
    -D CONFIG_ASYNC_TCP_STACK_SIZE=16384
```

### 📝 Детали изменений

#### Файлы изменены:
- `include/WebServer.h` - обновлен тип сервера на `AsyncWebServer`
- `src/WebServer.cpp` - переписаны все обработчики на новый синтаксис
- `platformio.ini` - обновлены зависимости и флаги компиляции
- `docs/TROUBLESHOOTING.md` - добавлен раздел о решении паник
- `docs/ESP32-C3_COMPILATION_FIXES.md` - добавлена информация о веб-сервере
- `docs/INTEGRATION_ROADMAP.md` - обновлены зависимости

### ⚠️ Breaking Changes

**Нет критических breaking changes.** API остался совместимым, изменения касаются только внутренней реализации веб-сервера.

### 🐛 Исправленные ошибки

- Исправлена паника "Guru Meditation Error: Core 0 panic'ed (Load access fault)" при работе веб-сервера
- Устранены проблемы с обработкой HTTP запросов на ESP32-C3
- Улучшена стабильность при множественных одновременных подключениях

### 📚 Документация

- Добавлен раздел "Веб-сервер вызывает панику" в `TROUBLESHOOTING.md`
- Обновлены инструкции по настройке зависимостей
- Добавлены примеры конфигурации для ESP32-C3

## [1.0.0] - 2025-12-XX

### Первый релиз

#### Основной функционал
- Измерение алкоголя в растворах (0-100%)
- Температурная компенсация результатов
- OLED дисплей для отображения результатов
- Веб-интерфейс для удаленного мониторинга
- Wi-Fi подключение (режим клиента и точки доступа)
- OTA обновления прошивки по воздуху
- Логирование измерений с сохранением в файловую систему
- Калибровка для точных измерений

#### Компоненты
- Емкостный датчик на базе ESP32-C3
- Температурный датчик DS18B20
- OLED дисплей SSD1306 72x40
- Веб-интерфейс с 4 страницами
- RESTful API

#### Документация
- README.md с полным описанием проекта
- Документация по API
- Руководство по устранению неполадок
- Примеры использования
