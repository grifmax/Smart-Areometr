✅ Преимущества ADS1115:
• 16-битное разрешение (65536 vs 4096 уровней)
• Точность ±0.1-0.2% vs ±0.5-1%
• Стабильность 90-98% vs 70-85%
• 4 канала для расширения
• Дифференциальный режим (подавление помех)

СХЕМА 4: АВТОМАТИЗАЦИЯ (приемники)

ESP32-C3:
  GPIO7 ──► Реле 1 ──► Клапан 1 (Головы)     ─┐
  GPIO8 ──► Реле 2 ──► Клапан 2 (Тело)       ├─► 12V DC
  GPIO9 ──► Реле 3 ──► Клапан 3 (Хвосты)     ─┘

Детальная схема одного клапана:

                           ┌─── +12V
                           │
    ESP32-C3               │    Релейный модуль
     GPIO7                 │      ┌──────────┐
       │                   │      │  Реле 1  │
       ├───[1kΩ]───────────┼──────┤ IN1  COM │
       │                   │      │      NO  │────┐
      GND                  │      └──────────┘    │
                           │                      │
                           │      Соленоид        │
                           │      ┌─────────┐     │
                           └──────┤ Coil (+)│◄────┘
                                  │         │
                                  │ [Diode] │  ← 1N4007
                                  │ 1N4007  │     (защита)
                                  └────┬────┘
                                       │
                                      GND
⚠️ ВАЖНО: Диод 1N4007 обязателен для защиты от обратной ЭДС!
Без него реле и ESP32-C3 могут выйти из строя.
