# Pull Request: Smart Areometr v2.0.0

## 🎯 Цель PR

Критическое обновление для исправления проблем стабильности веб-сервера на ESP32-C3. Переход на поддерживаемый форк ESPAsyncWebServer устраняет паники и улучшает совместимость.

## 📋 Описание изменений

### Основная проблема
- **Ошибка:** `Guru Meditation Error: Core 0 panic'ed (Load access fault)`
- **Причина:** Библиотека `ESPAsyncWebServer-esphome` несовместима с ESP32-C3
- **Решение:** Переход на поддерживаемый форк `ESP32Async/ESPAsyncWebServer`

### Технические изменения
- ✅ Заменена библиотека веб-сервера на поддерживаемый форк
- ✅ Обновлены все обработчики на новый синтаксис AsyncWebServer
- ✅ Добавлены флаги компиляции для совместимости
- ✅ Увеличен размер стека AsyncTCP до 16384 байт
- ✅ Обновлена версия до 2.0.0
