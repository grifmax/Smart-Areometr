# Pull Request: Smart Areometr v2.0.0 - Стабильность веб-сервера на ESP32-C3

## 📋 Краткое описание

**Версия:** 2.0.0  
**Дата:** 2025-12-17  
**Ветка:** `claude/coding-session-start-dxTxz`

Критическое обновление, исправляющее проблемы стабильности веб-сервера на ESP32-C3. Переход на поддерживаемый форк ESPAsyncWebServer для устранения паник и улучшения совместимости.

---

## 🎯 Основная проблема

### Guru Meditation Error при работе веб-сервера

**Симптомы:**
- Ошибка: `Guru Meditation Error: Core 0 panic'ed (Load access fault)`
- Перезагрузка устройства при обращении к веб-интерфейсу
- Ошибка в `AsyncWebServer::_rewriteRequest`
- Нестабильная работа на ESP32-C3

**Причина:**
Библиотека `ESPAsyncWebServer-esphome` имеет проблемы совместимости с ESP32-C3 и вызывает паники при обработке HTTP запросов.

**Решение:**
Переход на поддерживаемый форк `ESP32Async/ESPAsyncWebServer`, который активно поддерживается сообществом и совместим с ESP32-C3.

## 🚀 Как протестировать

### 1. Обновление зависимостей
```bash
# Очистка старых библиотек
pio run --target clean

# Установка новых зависимостей
pio pkg update
```

### 2. Сборка проекта
```bash
# Сборка
pio run

# Проверка на ошибки компиляции
pio run -v
```

### 3. Загрузка на устройство
```bash
# Загрузка прошивки
pio run --target upload

# Загрузка файловой системы (если нужно)
pio run --target uploadfs
```

### 4. Тестирование веб-сервера
1. Подключитесь к точке доступа `Areometr_AP`
2. Откройте браузер: `http://192.168.4.1`
3. Проверьте все страницы:
   - `/` - главная страница
   - `/calibration.html` - калибровка
   - `/settings.html` - настройки
   - `/logs.html` - логи
4. Проверьте API endpoints:
   ```bash
   curl http://192.168.4.1/api/status
   curl http://192.168.4.1/api/measurement
   ```

### 5. Проверка стабильности
- Откройте веб-интерфейс и оставьте на несколько минут
- Проверьте Serial Monitor на наличие ошибок
- Убедитесь, что нет перезагрузок
- Проверьте работу при множественных запросах
