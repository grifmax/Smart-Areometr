# Pull Request: Smart Areometr - Complete IoT Alcohol Meter Implementation

## 📋 Краткое описание

Полная реализация умного ареометра для измерения содержания алкоголя в растворах на базе ESP32-C3 с:
- ✅ Емкостным датчиком и температурной компенсацией
- ✅ Современным веб-интерфейсом (4 страницы, графики, real-time)
- ✅ RESTful API для интеграций
- ✅ Подробной документацией (5 документов)

---

## ✨ Основной функционал

### Измерительная система
- **Емкостный датчик** - touchRead() ESP32-C3
- **Температурная компенсация** - DS18B20 (±0.5°C)
- **Двухточечная калибровка** - вода + спирт
- **Точность** - ±2% после калибровки
- **Диапазон** - 0-100% алкоголя

### Интерфейсы
- **OLED дисплей** - SSD1306 0.42" для real-time отображения
- **Веб-интерфейс** - 4 адаптивные страницы с Chart.js
- **RESTful API** - 7 endpoints
- **Кнопки управления** - калибровка и измерение

### Сетевые возможности
- **Wi-Fi** - AP и Client режимы
- **OTA** - обновления по воздуху
- **AsyncWebServer** - статические файлы из LittleFS

## 🚀 Как протестировать

### Сборка и загрузка
```bash
git checkout claude/coding-session-start-dxTxz
pio run                    # Сборка
pio run --target upload    # Загрузка прошивки
pio run --target uploadfs  # Загрузка веб-интерфейса (важно!)
```

### Подключение
1. ESP32 создаст точку доступа `Areometr_AP` (пароль: `12345678`)
2. Подключитесь к Wi-Fi
3. Откройте http://192.168.4.1

### Калибровка
1. Перейдите на страницу "Калибровка"
2. Погрузите датчик в чистую воду → "Калибровать на воде"
3. Промойте датчик
4. Погрузите в чистый спирт (96%) → "Калибровать на спирте"

### Измерение
1. Погрузите датчик в раствор
2. Результат на дисплее и в веб-интерфейсе
3. График обновляется автоматически
