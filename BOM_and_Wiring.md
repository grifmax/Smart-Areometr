```
Формула расчета напряжения батареи:
V_bat = V_adc × BATTERY_DIVIDER_RATIO
V_bat = (ADC_value / 4095) × 3.3V × 2.0

Процент заряда:
Battery_% = (V_bat - 3.0V) / (4.2V - 3.0V) × 100%

Конфигурация config.h:
#define BATTERY_MONITOR_ENABLED true
#define BATTERY_ADC_PIN GPIO_NUM_1
#define BATTERY_VOLTAGE_MIN 3.0f    // Полный разряд
#define BATTERY_VOLTAGE_MAX 4.2f    // Полный заряд
#define BATTERY_LOW_THRESHOLD 20    // Предупреждение при 20%
#define BATTERY_CRITICAL_THRESHOLD 10  // Критический заряд 10%
#define BATTERY_DIVIDER_RATIO 2.0f  // Коэффициент делителя
```

**Индикаторы состояния батареи:**
- 🟢 100-80%: Полный заряд
- 🟡 80-50%: Средний заряд
- 🟠 50-20%: Низкий заряд (предупреждение)
- 🔴 <20%: Критический заряд (требуется зарядка)

**Режимы энергосбережения:**
- При заряде <20%: снижение частоты измерений
- При заряде <10%: возможен Deep Sleep между измерениями
- При критическом заряде: уведомления через MQTT/веб

**Логика автоматического управления:**

```
1. FractionDetector анализирует крепость и скорость изменения
   ↓
2. Определяет фракцию: FORESHOTS → HEADS → BODY → TAILS → FINISHED
   ↓
3. ReceiverController открывает соответствующий клапан:
   - HEADS (20-78%) → Клапан 1 (GPIO7)
   - BODY (78-92%) → Клапан 2 (GPIO8)
   - TAILS (>92%) → Клапан 3 (GPIO9)
   ↓
4. LevelDetector (AIN2) отслеживает уровень в приемнике
   ↓
5. При переполнении → автоматическое переключение на следующий
```

**Настройка config.h:**
```cpp
#define RECEIVER_CONTROL_ENABLED true
#define RECEIVER_COUNT 3
#define RECEIVER_1_PIN GPIO_NUM_7  // Головы
#define RECEIVER_2_PIN GPIO_NUM_8  // Тело
#define RECEIVER_3_PIN GPIO_NUM_9  // Хвосты
#define RECEIVER_MAX_VOLUME_ML 1000.0f  // Максимальный объем

#define RECEIVER_LEVEL_DETECTION_ENABLED true
#define ADS1115_LEVEL_CHANNEL 2  // AIN2 для детекции уровня
#define LEVEL_DETECTION_THRESHOLD 0.5f  // Порог переполнения (В)
```

**Варианты действий при переполнении:**
- `SWITCH_NEXT`: Переключить на следующий приемник (по умолчанию)
- `STOP`: Остановить процесс и выдать предупреждение
- `NOTIFY_ONLY`: Только уведомление без переключения

## 📊 I2C АДРЕСА УСТРОЙСТВ

| Устройство | I2C Адрес | Изменяемый | Примечание |
|------------|-----------|------------|------------|
| **OLED SSD1306** | 0x3C | Нет | Встроенный в плату ESP32-C3 |
| **ADS1115** | 0x48 | Да | По умолчанию, можно: 0x49, 0x4A, 0x4B |
| **BMP280** | 0x76 | Да | Альтернативный: 0x77 |
| **BME280** | 0x76 | Да | Альтернативный: 0x77 |

### Изменение адреса ADS1115

Адрес ADS1115 настраивается перемычкой на пине ADDR:

| ADDR подключен к | I2C Адрес |
|------------------|-----------|
| GND | 0x48 (по умолчанию) |
| VDD | 0x49 |
| SDA | 0x4A |
| SCL | 0x4B |

### Проверка I2C устройств

```cpp
// I2C Scanner код для проверки подключенных устройств
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(5, 6); // SDA=GPIO5, SCL=GPIO6

  Serial.println("\nI2C Scanner");
  for(byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if(Wire.endTransmission() == 0) {
      Serial.print("Found device at 0x");
      if(addr < 16) Serial.print("0");
      Serial.println(addr, HEX);
    }
  }
}
```

**Ожидаемый вывод (базовая конфигурация с ADS1115):**
```
Found device at 0x3C  (OLED SSD1306)
Found device at 0x48  (ADS1115)
```

## ⚡ ПИТАНИЕ

### Режимы энергопотребления

| Режим | Потребление | Wi-Fi | Измерения | Примечание |
|-------|-------------|-------|-----------|------------|
| **Активный** | ~150mA | ✅ Вкл | Каждые 5 сек | Нормальный режим работы |
| **Экономичный** | ~80-100mA | ✅ Вкл | Каждые 30 сек | Снижена частота измерений |
| **Deep Sleep** | ~10-20mA | ❌ Выкл | По таймеру | Пробуждение каждые 60 сек |
| **Приемники активны** | +500mA × N | - | - | N = количество открытых клапанов |

### Расчет времени автономной работы

**Формула:**
```
Время работы (часы) = Емкость батареи (mAh) / Потребление (mA)
```

**Примеры:**

| Батарея | Режим | Потребление | Время работы |
|---------|-------|-------------|--------------|
| 2000 mAh | Активный | 150 mA | ~13 часов |
| 2000 mAh | Экономичный | 100 mA | ~20 часов |
| 2000 mAh | Deep Sleep | 20 mA | ~100 часов (4 дня) |
| 3000 mAh | Активный | 150 mA | ~20 часов |
| 3000 mAh | Deep Sleep | 20 mA | ~150 часов (6 дней) |

**Примечание:** Реальное время может быть на 10-20% меньше из-за неидеальности преобразователей и саморазряда батареи.

### Рекомендуемые источники питания

#### Для базовой версии (без приемников)
- **USB 5V 1A** - минимум
- **USB 5V 2A** - рекомендуется

#### Для автономной версии
- **Li-Ion 18650 2000-3000mAh** - оптимальный баланс
- **TP4056 модуль с защитой** - обязательно с DW01A
- **Делитель напряжения 10kΩ + 10kΩ** - для мониторинга

#### Для версии с автоматизацией

- **БП 12V 2A** - для соленоидных клапанов
- Или **единый БП 12V 3A** + понижающий DC-DC 12V→5V 3A

### Защита питания

**Обязательные элементы защиты:**
1. **Диод Шоттки** (1N5819) на входе питания - защита от обратной полярности
2. **Конденсаторы фильтрации:**
   - 100µF электролитический на входе VIN
   - 10µF керамический на выходе 3.3V
   - 0.1µF на каждом I2C устройстве
3. **TVS диод** (P6KE6.8A) - защита от всплесков напряжения
4. **Предохранитель** 2A самовосстанавливающийся (PTC)

## 🔨 ИНСТРУКЦИЯ ПО СБОРКЕ

### Шаг 1: Подготовка компонентов

1. Проверьте наличие всех компонентов по BOM
2. Подготовьте инструменты:
   - Паяльник (60-80W)
   - Припой (с флюсом)
   - Кусачки, пинцет
   - Мультиметр
   - Термоусадка и фен

### Шаг 2: Сборка емкостного датчика

**Вариант 1: Плоские электроды**
1. Вырежьте 2 пластины из нержавейки (30×10×0.5мм)
2. Зачистите поверхность наждачной бумагой P400
3. Обезжирьте спиртом
4. Припайте провода (медь луженая 0.5мм²)
5. Установите параллельно с зазором 5-10мм
6. Герметизируйте эпоксидной смолой (оставив 20мм рабочей части)
7. Дайте застыть 24 часа

**Вариант 2: Коаксиальная конструкция**
1. Трубки из нержавейки: внешняя Ø12мм, внутренняя Ø6мм
2. Длина: 50мм рабочей части + 30мм для крепления
3. Изолирующие кольца из PTFE (фторопласт) каждые 10мм
4. Припайте провода к каждой трубке
5. Герметизируйте верх эпоксидкой

### Шаг 3: Подключение DS18B20

1. Если TO-92 версия:
   - Припайте резистор 4.7kΩ между VCC и DATA
   - Провода: GND (черный), DATA (желтый), VCC (красный)
   - Изолируйте термоусадкой

2. Если водонепроницаемая версия:
   - Резистор уже встроен
   - Подключите согласно цветам проводов

### Шаг 4: Монтаж ADS1115

1. Припайте pin headers к модулю ADS1115
2. Подключите к breadboard или напрямую к ESP32-C3
3. Соединения:
   - VDD → 3.3V
   - GND → GND
   - SDA → GPIO5
   - SCL → GPIO6
   - ADDR → GND (для адреса 0x48)

### Шаг 5: Подключение кнопок

1. Припайте кнопки к GPIO3 и GPIO4
2. Второй контакт каждой кнопки → GND
3. Внутренний PULLUP включен в коде, внешний резистор не нужен

### Шаг 6: Батарея и зарядка (опционально)

1. **Делитель напряжения:**
   ```
   BAT+ ──[R1 10kΩ]──┬──► GPIO1
                     │
                 [R2 10kΩ]
                     │
                    GND
   ```

2. **TP4056 подключение:**
   - BAT+ и BAT- → к аккумулятору
   - OUT+ → VIN ESP32-C3 (через выключатель)
   - OUT- → GND ESP32-C3
   - USB-C → зарядка

3. **Установите выключатель** между TP4056 OUT+ и VIN

### Шаг 7: Приемники и реле (опционально)

1. **Подключение реле:**
   - Реле VCC → 5V
   - Реле GND → GND
   - Реле IN1 → GPIO7
   - Реле IN2 → GPIO8
   - Reле IN3 → GPIO9

2. **Подключение клапанов:**
   - Реле COM → +12V
   - Реле NO → Клапан (+)
   - Клапан (-) → GND
   - **Диод 1N4007 параллельно каждому клапану** (катод к +12V)

### Шаг 8: Монтаж в корпус

1. Разметьте отверстия для:
   - USB-C разъем (зарядка)
   - Кабельные вводы (датчики)
   - Кнопки (если выносные)
   - OLED дисплей (окно)

2. Установите стойки M3 для крепления платы
3. Проложите провода аккуратно, используйте стяжки
4. Установите кабельные вводы PG7
5. Проверьте изоляцию всех соединений

### Шаг 9: Проверка перед включением

**Обязательная проверка мультиметром:**
1. ✅ Короткое замыкание VCC-GND (должно быть >1МОм)
2. ✅ Напряжение батареи (3.7-4.2V)
3. ✅ Полярность всех подключений
4. ✅ Сопротивление датчиков (не 0 и не бесконечность)

### Шаг 10: Первое включение

1. Подключите USB (без батареи сначала)
2. Проверьте Serial Monitor (115200 baud)
3. Должны появиться сообщения инициализации
4. Проверьте веб-интерфейс (192.168.4.1 в режиме AP)
5. Выполните I2C scan (должен найти 0x3C и 0x48)

## 🆘 УСТРАНЕНИЕ НЕПОЛАДОК

### ADS1115 не обнаружен

**Проблема:** I2C scan не находит устройство 0x48

**Решения:**
1. Проверьте подключение SDA/SCL
2. Проверьте питание VDD (должно быть 3.3V)
3. Проверьте адресную перемычку ADDR
4. Попробуйте другой адрес (0x49, 0x4A, 0x4B)
5. Измерьте напряжение на SDA/SCL (должно быть ~3.3V в idle)

### Нестабильные показания крепости

**Проблема:** Значения прыгают ±5-10%

**Решения:**
1. Очистите электроды (спирт + мягкая ткань)
2. Проверьте качество соединений (пропайка)
3. Увеличьте `MEASUREMENT_SAMPLES` в config.h (до 200)
4. Проверьте заземление (общий GND)
5. Используйте экранированный кабель для датчика
6. Убедитесь что датчик полностью погружен

### Приемники не переключаются

**Проблема:** Клапаны не открываются автоматически

**Решения:**
1. Проверьте питание 12V для клапанов
2. Проверьте реле (должен быть щелчок)
3. Проверьте диоды защиты (правильная полярность)
4. Включите `RECEIVER_CONTROL_ENABLED` в config.h
5. Проверьте пороги фракций в `/fractions.html`
6. Проверьте логи: `Serial.println()` в ReceiverController

### Батарея показывает неверный процент

**Проблема:** Заряд всегда 100% или 0%

**Решения:**
1. Проверьте делитель напряжения (R1=R2=10kΩ)
2. Проверьте подключение к GPIO1
3. Откалибруйте `BATTERY_VOLTAGE_MIN/MAX` в config.h
4. Измерьте реальное напряжение батареи мультиметром
5. Проверьте `BATTERY_DIVIDER_RATIO` (должно быть 2.0)
