# Changelog версии 2.1.x

## Версия 2.1.14 (2025-01-XX)

### Исправлено
- ✅ **Deep Sleep отключен по умолчанию** - предотвращает неожиданное отключение Wi-Fi
- ✅ **Исправлена тряска графиков** - оптимизировано обновление графиков в receivers.html
- ✅ **Оптимизировано обновление UI** - предотвращена перерисовка всей страницы при обновлении статуса
- ✅ **Исправлена ошибка ERR_CONNECTION_RESET** - добавлена обработка ошибок для API endpoints приемников
- ✅ **Добавлены маршруты для новых файлов** - i18n.js, receivers.js, sensors.js теперь доступны через веб-сервер

### Изменено
- Улучшена стабильность веб-интерфейса
- Оптимизирована работа с графиками Chart.js
- Добавлена фиксированная высота для контейнера графика
- Улучшена обработка ошибок в API endpoints
