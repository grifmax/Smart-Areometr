# Руководство по точной калибровке Smart Areometr

## 📐 Почему важна точная калибровка

### Проблема линейной калибровки

Простая двухточечная калибровка (вода + спирт) предполагает **линейную** зависимость между показаниями датчика и крепостью. Но на самом деле эта зависимость **нелинейна**!

```
Диэлектрическая проницаемость:
- Вода:   ε ≈ 80
- Этанол: ε ≈ 24

Реальная зависимость имеет изгиб (особенно в диапазоне 40-96%)
```

**Погрешность при линейной калибровке:**
- 0-20%: ±1-2%
- 20-60%: ±3-5%  ⚠️
- 60-90%: ±2-4%

**Погрешность при многоточечной калибровке:**
- Весь диапазон: ±1-2% ✅

---

## 🎯 Система многоточечной калибровки

### Принцип работы

1. **Множество опорных точек** (до 10 шт)
   - Измеряем растворы с известной крепостью
   - Сохраняем пары: `(крепость% → сырое значение датчика)`

2. **Линейная интерполяция между точками**
   - Для неизвестного значения находим две ближайшие точки
   - Вычисляем по формуле: `y = y₀ + (x - x₀) × (y₁ - y₀) / (x₁ - x₀)`

3. **Температурная коррекция по ГОСТ**
   - Используем таблицы ГОСТ 3639-79
   - Билинейная интерполяция для точных значений

### Пример калибровочной кривой

```
Точки калибровки:
  0% → 150.0  (вода)
 40% → 115.0  (водка)
 70% → 95.0   (спирт 70%)
 96% → 75.0   (спирт)

Измерение: сырое значение = 105.0
Находим интервал: 105.0 находится между 115.0 (40%) и 95.0 (70%)

Интерполяция:
alcohol = 40 + (105 - 115) × (70 - 40) / (95 - 115)
        = 40 + (-10) × 30 / (-20)
        = 40 + 15
        = 55%
```

## 🧪 Приготовление калибровочных растворов

### Формула разбавления

```
V_воды = V_спирта × (C_исх - C_цел) / C_цел

Где:
V_воды - объем воды для добавления (мл)
V_спирта - объем исходного спирта (мл)
C_исх - исходная крепость (%)
C_цел - целевая крепость (%)
```

### Примеры расчетов

**Получить 1000 мл раствора 40% из спирта 96%:**
```
V_спирта = 1000 × 40 / 96 = 417 мл спирта
V_воды = 1000 - 417 = 583 мл воды
```

**Получить 1000 мл раствора 70% из спирта 96%:**
```
V_спирта = 1000 × 70 / 96 = 729 мл спирта
V_воды = 1000 - 729 = 271 мл воды
```

**Получить 1000 мл раствора 55% из спирта 96%:**
```
V_спирта = 1000 × 55 / 96 = 573 мл спирта
V_воды = 1000 - 573 = 427 мл воды
```

## 🌡️ Температурная коррекция (ГОСТ 3639-79)

### Как работает

Плотность и диэлектрическая проницаемость водно-спиртовых растворов **зависят от температуры**.

При температуре **выше 20°C**:
- Плотность уменьшается
- Показания спиртометра **занижены**
- Нужно **прибавлять** поправку

При температуре **ниже 20°C**:
- Плотность увеличивается
- Показания **завышены**
- Нужно **вычитать** поправку

### Таблица поправок

Для **40% раствора** при разных температурах:

| Температура | Поправка | Реальная крепость |
|-------------|----------|-------------------|
| 10°C | -2.08% | 42.08% |
| 15°C | -1.04% | 41.04% |
| **20°C** | **0.00%** | **40.00%** ← эталон |
| 25°C | +2.60% | 37.40% |
| 30°C | +4.16% | 35.84% |

**Пример:**
Измерили при 25°C: показания = 40%
Реальная крепость = 40% - 2.60% = **37.4%**

### Билинейная интерполяция

Наша система использует **полную таблицу ГОСТ** с интерполяцией для:
- Любой температуры от 0°C до 40°C
- Любой крепости от 0% до 100%

**Точность:** ±0.1% 🎯

## 🔬 Процесс калибровки

### Подготовка

1. **Приготовьте калибровочные растворы**
   - Используйте чистую посуду
   - Точно отмеряйте объемы (мерный цилиндр)
   - Дайте растворам постоять 10-15 минут

2. **Подготовьте датчик**
   - Промойте дистиллированной водой
   - Высушите мягкой тканью
   - Убедитесь в отсутствии загрязнений

3. **Условия измерения**
   - Температура: 18-22°C (оптимально 20°C)
   - Минимальный объем раствора: 50 мл
   - Стакан из стекла или пластика

### Пошаговая инструкция

#### Шаг 1: Первая точка (Вода, 0%)

1. Налейте дистиллированную воду в стакан
2. Погрузите датчик на глубину 3-5 см
3. Подождите 15-20 секунд для стабилизации
4. В веб-интерфейсе: "Добавить точку" → 0%
5. Запишите показания: `0% → XXX.X`

#### Шаг 2: Вторая точка (Водка, 40%)

1. Промойте датчик водой и протрите
2. Налейте водку 40° в чистый стакан
3. Погрузите датчик
4. Подождите стабилизации
5. Добавьте точку: `40% → YYY.Y`

#### Шаг 3: Третья точка (Спирт 70%)

1. Промойте датчик
2. Используйте приготовленный раствор 70%
3. Добавьте точку: `70% → ZZZ.Z`

#### Шаг 4: Четвертая точка (Спирт 96%)

1. Промойте датчик спиртом (для удаления воды)
2. Погрузите в чистый спирт 96%
3. Добавьте точку: `96% → WWW.W`

#### Шаг 5: Сохранение и проверка

1. Нажмите "Сохранить калибровку"
2. Система построит калибровочную кривую
3. Проверьте на известном растворе (например, водка 40%)

## ✅ Проверка точности калибровки

### Метод 1: Контрольный раствор

Приготовьте раствор известной крепости (не из калибровочных точек):

```
Например: 50% раствор
Спирт 96%: 521 мл
Вода:      479 мл
```

Измерьте ареометром:
- **Отклонение ±1%** → Отлично ✅
- **Отклонение ±2%** → Хорошо ✓
- **Отклонение >3%** → Требуется повторная калибровка ⚠️

### Метод 2: Сравнение с эталонным спиртометром

Если есть стеклянный спиртометр:
1. Измерьте один и тот же раствор обоими приборами
2. Сравните показания при одинаковой температуре
3. Разница должна быть менее 1-2%

### Метод 3: Проверка монотонности

Калибровочная кривая должна быть **монотонной** (без скачков):

```
Правильно:
0% → 150
40% → 115  ✓ (уменьшается)
70% → 95   ✓ (уменьшается)
96% → 75   ✓ (уменьшается)

Неправильно:
0% → 150
40% → 115  ✓
70% → 120  ✗ (увеличилось!)
96% → 75   ✓
```

Если есть скачки → повторите измерение этой точки.

## 🛠️ Устранение проблем

### Большой разброс показаний

**Причины:**
- Недостаточная стабилизация
- Пузырьки воздуха на электродах
- Загрязненный датчик

**Решение:**
- Увеличьте время ожидания до 30 сек
- Слегка постучите по датчику
- Тщательно промойте датчик

### Нелинейная кривая

**Причина:**
- Неточность приготовления растворов
- Ошибка в температуре

**Решение:**
- Пересчитайте пропорции разбавления
- Используйте точные мерные инструменты
- Дайте растворам прогреться до комнатной температуры

### Дрейф показаний

**Причина:**
- Испарение спирта (для крепких растворов)
- Изменение температуры

**Решение:**
- Храните растворы в закрытых емкостях
- Проводите калибровку при стабильной температуре
- Работайте быстро

2. Сохраните JSON файл на компьютер
3. Можете импортировать на другое устройство

## 🎓 Дополнительные материалы

### Научные основы

**Диэлектрическая проницаемость смесей:**
```
ε_смеси ≠ ε₁ × V₁ + ε₂ × V₂  (не линейна!)

Формула Клаузиуса-Моссотти:
(ε - 1)/(ε + 2) = Σ Nᵢαᵢ

Где:
ε - диэлектрическая проницаемость
Nᵢ - концентрация молекул i-го типа
αᵢ - поляризуемость молекул
```
