- Используйте коаксиальную конструкцию (внешний и внутренний цилиндр)

- Внутренний цилиндр → AIN1 (ADS1115) или GND (встроенный ADC)
- Диаметр внешнего: 10-15мм
- Диаметр внутреннего: 5-8мм

### ADS1115 модуль (16-битный внешний АЦП)

**Рекомендуется для повышения точности измерений!**

```
ADS1115 Module:
                    ┌─────────────┐
                    │   ADS1115   │
                    │   Module    │
                    └──────┬──────┘
                           │
        ESP32-C3           │
        ┌─────────┐        │
        │ GPIO5   │────────┼──► SDA (I2C Data)
        │ GPIO6   │────────┼──► SCL (I2C Clock)
        │ 3.3V    │────────┼──► VDD (Power)
        │ GND     │────────┼──► GND (Ground)
        └─────────┘        │
                           │
        Электроды          │
        ┌─────────┐        │
        │Электрод1│────────┼──► AIN0 (Differential +)
        │Электрод2│────────┼──► AIN1 (Differential -)
        └─────────┘        │
                    └─────────────┘
```

**Подключение:**
- **SDA** → GPIO5 (общая I2C шина с OLED)
- **SCL** → GPIO6 (общая I2C шина с OLED)
- **VDD** → 3.3V
- **GND** → GND
- **AIN0** → Электрод 1 (положительный)
- **AIN1** → Электрод 2 (отрицательный)

**Преимущества ADS1115:**
- ✅ 16-битное разрешение (65536 уровней вместо 4096)
- ✅ Дифференциальный режим (подавление помех)
- ✅ Программируемое усиление (1×, 2×, 4×, 8×)
- ✅ Точность ±0.1-0.2% вместо ±0.5-1%
- ✅ Стабильность 90-98% вместо 70-85%

**Настройка:**
- Адрес I2C: 0x48 (по умолчанию, можно изменить перемычками)
- Усиление: 4× (рекомендуется для малых сигналов)
- Скорость выборки: 128 SPS (баланс скорость/шум)

**Примечание:** Если ADS1115 не подключен, система автоматически использует встроенный 12-битный ADC ESP32-C3.

**Настройка и калибровка ADS1115:**
- Инициализация происходит автоматически при запуске
- Статус можно проверить через веб-интерфейс: `/api/ads1115/status`
- Напряжение дифференциального сигнала отображается в API `/api/measurement` (поле `signal_voltage`)
- Разрешение АЦП показывается в веб-интерфейсе (16-bit для ADS1115, 12-bit для встроенного)

### Детектор уровня жидкости (защита от переполнения)

Для автоматического определения переполнения приемников используется дополнительный канал ADS1115 (AIN2) с проводящим методом детекции.

```
Схема подключения детектора уровня:

ADS1115 Module:
                    ┌─────────────┐
                    │   ADS1115   │
                    │   Module    │
                    └──────┬──────┘
                           │
        Электроды          │
        ┌─────────┐        │
        │Электрод1│────────┼──► AIN2 (Level detection)
        │(верхний)│        │
        └─────────┘        │
        ┌─────────┐        │
        │Электрод2│────────┼──► GND
        │(нижний) │        │
        └─────────┘        │
                    └─────────────┘

        Приемник:
        ┌─────────────────┐
        │                 │
        │   ⚠️ ПЕРЕПОЛНЕНИЕ │ ← Электрод 1 здесь
        │   ───────────── │
        │                 │
        │    Жидкость     │
        │                 │
        │   ───────────── │ ← Электрод 2 здесь
        │                 │
        └─────────────────┘
```

**Подключение:**
- **AIN2** (ADS1115) → Верхний электрод (на уровне переполнения)
- **GND** → Нижний электрод (базовый уровень)
- Используется тот же ADS1115 модуль, что и для основного датчика крепости

**Конструкция электродов:**
- Два электрода из нержавеющей стали
- Верхний электрод размещается на уровне "переполнение" в приемнике
- Нижний электрод - на базовом уровне (или корпус приемника)
- Расстояние между электродами: 10-20мм
- Размеры: 20x5мм каждый

**Принцип работы:**
1. Когда жидкость не достигает верхнего электрода - сопротивление высокое, напряжение низкое
2. Когда жидкость достигает верхнего электрода - появляется проводимость, напряжение растет
3. При превышении порогового напряжения (настраивается, по умолчанию 0.5В) - срабатывает защита от переполнения

**Схема делителя напряжения (опционально):**

Для более надежной работы можно использовать делитель напряжения:

```
        VCC (3.3V)
           │
           ├──[10kΩ]──┬──► AIN2
           │          │
        Электрод1    │
          │          │
          │       [100kΩ]
          │          │
        Электрод2    │
          │          │
          └──────────┴──► GND
```

**Настройка:**
- Порог переполнения устанавливается через веб-интерфейс (`/receivers.html`)
- Калибровка выполняется через веб-интерфейс: "Пустой приемник" и "Полный приемник"
- Статус можно проверить через API: `/api/receivers/level/status`

**Примечание:** 
- Детектор уровня работает только с ADS1115 (использует канал AIN2)
- Если ADS1115 не подключен, функция защиты от переполнения недоступна
- Для работы требуется электропроводящая жидкость (спиртовые растворы проводят ток)

### Мониторинг батареи

Система поддерживает мониторинг заряда Li-Ion аккумулятора через встроенный ADC ESP32-C3.

```
Подключение батареи через TP4056:

┌──────────────┐
│   Li-Ion     │
│   Battery    │
│   3.7V       │
└──────┬───────┘
       │
       ▼
┌──────────────┐      ┌─────────────┐
│   TP4056     │──────│  ESP32-C3   │
│  Charger     │      │             │
│  Module      │      │  GPIO1 ─────┼──► ADC для измерения
└──────┬───────┘      │             │      напряжения батареи
       │              │             │
       ▼              └─────────────┘
┌──────────────┐
│  USB-C       │
│  Power       │
└──────────────┘
```

**Схема подключения:**
1. **TP4056 модуль** (зарядное устройство):
   - **BAT+** → Плюс аккумулятора
   - **BAT-** → Минус аккумулятора
   - **OUT+** → VIN ESP32-C3 (или 5V через стабилизатор)
   - **OUT-** → GND ESP32-C3
   - **USB-C** → Питание для зарядки

2. **Измерение напряжения:**
   - Используйте делитель напряжения (например, два резистора 10кΩ)
   - Средняя точка делителя → GPIO1 (BATTERY_ADC_PIN)
   - Максимальное напряжение на GPIO1 должно быть ≤ 3.3V
   - Коэффициент делителя: 2.0 (настраивается в `config.h`)

**Конфигурация в config.h:**
```cpp
#define BATTERY_MONITOR_ENABLED true
#define BATTERY_ADC_PIN GPIO_NUM_1
#define BATTERY_VOLTAGE_MIN 3.0f    // Минимальное напряжение (В) - полный разряд
#define BATTERY_VOLTAGE_MAX 4.2f    // Максимальное напряжение (В) - полный заряд
#define BATTERY_LOW_THRESHOLD 20    // Порог низкого заряда (%)
#define BATTERY_CRITICAL_THRESHOLD 10  // Порог критического заряда (%)
#define BATTERY_DIVIDER_RATIO 2.0f  // Коэффициент делителя напряжения
```

**Особенности:**
- Автоматическое обновление каждые 30 секунд
- Отображение на OLED дисплее с индикатором заряда
- Виджет в веб-интерфейсе с процентом и напряжением
- MQTT интеграция для публикации статуса
- Режим энергосбережения при низком заряде
- Предупреждения при критическом заряде

**Рекомендации по выбору аккумулятора:**
- **Емкость:** 1000-2000 mAh (компромисс размер/время работы)
- **Напряжение:** 3.7V номинальное, 4.2V максимум при зарядке
- **Тип:** Li-Ion (18650 или плоский)
- **Защита:** Рекомендуется использовать модуль TP4056 с защитой от перезаряда/переразряда

**Энергосбережение:**
- При заряде < 20%: снижается частота измерений
- При заряде < 10%: возможна отправка предупреждений
- При критическом заряде: рекомендуется подключить зарядку

## Сборка

### Шаг 1: Подготовка платы

1. Распакуйте ESP32-C3 плату
2. Проверьте работоспособность дисплея (загрузите тестовую программу)
3. Припайте pin headers если не установлены

### Шаг 2: Создание емкостного датчика

**Вариант 1: Плоские электроды**

1. Вырежьте 2 пластины из нержавеющей стали (30x10мм)
2. Зачистите поверхность мелкой наждачной бумагой
3. Припайте провода к каждому электроду
4. Установите электроды параллельно на расстоянии 5-10мм
5. Используйте эпоксидную смолу для изоляции соединений
6. Оставьте рабочую часть электродов открытой (20мм)

**Вариант 2: Коаксиальная конструкция**

1. Найдите две трубки из нержавеющей стали (разного диаметра)
2. Вставьте меньшую трубку в большую с зазором 2-3мм
3. Используйте изолирующие прокладки для фиксации
4. Припайте провода к каждой трубке
5. Герметизируйте верхнюю часть

### Шаг 3: Подключение DS18B20

1. Если используете TO-92 версию:
   - Припайте резистор 4.7кΩ между VCC и DATA
   - Подключите провода согласно схеме
   - Изолируйте датчик термоусадкой или герметиком

2. Если используете водонепроницаемую версию:
   - Просто подключите провода к плате
   - Резистор уже встроен

### Шаг 4: Установка кнопок

1. Припайте кнопки к GPIO3 и GPIO4
2. Второй контакт кнопок - на GND
3. Можно использовать breadboard для прототипа

### Шаг 5: Сборка в корпус

**Рекомендуемая конфигурация:**

```
┌────────────────────────────┐
│  ┌──────────┐              │
│  │  OLED    │              │
│  └──────────┘              │
│                            │
│  [CAL]  [MEAS]  [PWR LED]  │
│                            │
│  ┌──────────────────────┐  │
│  │   ESP32-C3 Плата     │  │
│  └──────────────────────┘  │
│                            │
│  ┌──────────────────────┐  │
│  │   Аккумулятор (опц.) │  │
│  └──────────────────────┘  │
│                            │
│  [USB-C разъем]            │
└────────────────────────────┘
         │
         │ Кабель датчиков
         ▼
   ┌──────────┐
   │ DS18B20  │
   └──────────┘
   ┌──────────┐
   │Емкостный │
   │ датчик   │
   └──────────┘
```

## Питание

### Вариант 1: USB питание

- Подключите USB кабель к ESP32-C3
- Напряжение: 5V
- Потребление: ~150mA

### Вариант 2: Аккумулятор + зарядка

**Схема подключения:**

```
USB-C ──► TP4056 ──► Li-Ion ──► ESP32-C3
           (зарядка)  3.7V      (VCC)
                      │
                      ├──► Делитель напряжения (R1=R2=10kΩ)
                      │
                      └──► GPIO1 (ADC для мониторинга)
```

**Компоненты:**
- Аккумулятор 18650 (3.7V, 2000mAh)
- Модуль TP4056 с защитой
- Два резистора 10kΩ для делителя напряжения
- Выключатель питания

**Подключение делителя напряжения:**
- GPIO1 → Средняя точка делителя (BAT+ через R1, GND через R2)
- R1 = R2 = 10kΩ (коэффициент деления 2:1)

**Настройка в config.h:**
```cpp
#define BATTERY_MONITOR_ENABLED true
#define BATTERY_ADC_PIN GPIO_NUM_1
#define BATTERY_VOLTAGE_MIN 3.0f    // Минимальное напряжение (В)
#define BATTERY_VOLTAGE_MAX 4.2f    // Максимальное напряжение (В)
#define BATTERY_LOW_THRESHOLD 20    // Порог низкого заряда (%)
#define BATTERY_DIVIDER_RATIO 2.0f  // Коэффициент делителя
```

**Время работы:**
- 2000mAh / 150mA ≈ 13 часов непрерывной работы

**Мониторинг заряда:**
- Напряжение батареи измеряется через ADC каждые 30 секунд
- Процент заряда вычисляется линейной интерполяцией между min и max напряжением
- При низком заряде (<20%) выводится предупреждение
- При критическом заряде (<10%) система может снизить частоту измерений для экономии энергии

**Калибровка:**
Для точной калибровки измерения заряда:
1. Измерьте напряжение полностью заряженной батареи (должно быть ~4.2V)
2. Измерьте напряжение разряженной батареи (должно быть ~3.0V)
3. При необходимости скорректируйте `BATTERY_VOLTAGE_MIN` и `BATTERY_VOLTAGE_MAX` в config.h

**Энергосбережение:**
- При низком заряде система может автоматически:
  - Снизить частоту измерений
  - Отключить Wi-Fi (если критически низкий заряд)
  - Войти в режим глубокого сна между измерениями

## Калибровка датчиков

### Емкостный датчик

**Что понадобится:**
- Дистиллированная вода
- Чистый спирт (96-99%)
- Два чистых стакана

**Процесс:**
1. Промойте датчик дистиллированной водой
2. Погрузите в воду для калибровки 0%
3. Промойте и высушите
4. Погрузите в спирт для калибровки 100%

**Проверка точности:**
- Используйте известные растворы (40%, 70%)
- Сравните показания с эталоном
- При необходимости скорректируйте коэффициенты

### Температурный датчик

DS18B20 обычно не требует калибровки, но можно проверить:
1. Опустите в тающий лед: должно быть 0°C
2. Опустите в кипящую воду: должно быть 100°C (с учетом давления)

## Техническое обслуживание

### Очистка датчиков

**Емкостный датчик:**
- После каждого использования промывайте водой
- Раз в неделю: очистка спиртом
- При загрязнении: механическая чистка мягкой щеткой

**Температурный датчик:**
- Протирайте мягкой тканью
- Не используйте абразивные материалы

### Замена компонентов

**Признаки неисправности:**
- Датчик температуры: постоянное значение -127°C
- Емкостный датчик: значение всегда 0 или максимум
- Дисплей: нет изображения или артефакты

## Улучшения конструкции

### 1. Автоматическая очистка датчика
- Добавьте соленоидный клапан для промывки
- Используйте перистальтический насос

### 2. Защита от влаги
- IP65 корпус для электроники
- Герметичные вводы для кабелей

### 3. Термостабилизация
- Элемент Пельтье для поддержания постоянной температуры
- Улучшит точность измерений

### 4. Расширенный функционал
- Добавьте pH датчик
- Датчик мутности раствора
- Оптический датчик цвета

## Безопасность

⚠️ **ВАЖНО:**
- Не погружайте электронику в жидкость
- Используйте влагозащищенный корпус
- При работе с спиртом соблюдайте меры пожарной безопасности
- Не используйте поврежденные аккумуляторы
- Заряжайте только под присмотром
