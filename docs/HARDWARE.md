## Детальная схема подключения

### Основная плата ESP32-C3

```
ESP32-C3 DevKit:
                    ┌─────────────┐
                    │             │
          GND ◄─────┤ GND         │
          3.3V ◄────┤ 3V3         │
                    │             │
OLED SDA (I2C) ◄────┤ GPIO8       │
OLED SCL (I2C) ◄────┤ GPIO9       │
                    │             │
 Touch Sensor  ◄────┤ GPIO2       │
   DS18B20     ◄────┤ GPIO10      │
                    │             │
 Button CAL    ◄────┤ GPIO3       │
 Button MEAS   ◄────┤ GPIO4       │
                    │             │
                    └─────────────┘
```

### Емкостный датчик

```
Конструкция емкостного датчика:

  ┌─────────────────────┐
  │   Изоляция (герметик/эпоксидка)
  │   ┌─────────────┐   │
  │   │ Электрод 1  │   │  ← к GPIO2
  │   │ (сталь)     │   │
  │   └─────────────┘   │
  │                     │
  │      ~5-10mm        │
  │                     │
  │   ┌─────────────┐   │
  │   │ Электрод 2  │   │  ← к GND
  │   │ (сталь)     │   │
  │   └─────────────┘   │
  │                     │
  └─────────────────────┘

Размеры электродов: 30x10мм
Материал: нержавеющая сталь
Толщина: 0.5-1мм
```

**Альтернативный вариант:**
- Используйте коаксиальную конструкцию (внешний и внутренний цилиндр)
- Внешний цилиндр → GPIO2
- Внутренний цилиндр → GND
- Диаметр внешнего: 10-15мм
- Диаметр внутреннего: 5-8мм

### Датчик температуры DS18B20

```
DS18B20 (TO-92):
     ┌─────┐
     │ ─── │  ← Flat side facing you
     └─┬─┬─┘
       │ │ │
       1 2 3
       │ │ │
       │ │ └── VCC (3.3V) + резистор 4.7кΩ к DATA
       │ └──── DATA (GPIO10)
       └────── GND
```

**Водонепроницаемая версия:**
```
Используйте готовую водонепроницаемую версию DS18B20:
   ┌──────────────┐
   │ Кабель       │
   │ (красный  = VCC)
   │ (черный   = GND)
   │ (желтый   = DATA)
   └──────────────┘
```

### Кнопки

```
Кнопка подключения (с подтяжкой):

        3.3V
         │
         └──┬── GPIO (3 или 4)
            │
         [КНОПКА]
            │
           GND

ESP32-C3 использует INPUT_PULLUP,
поэтому внешний резистор не нужен.
```

## Сборка

### Шаг 1: Подготовка платы

1. Распакуйте ESP32-C3 плату
2. Проверьте работоспособность дисплея (загрузите тестовую программу)
3. Припайте pin headers если не установлены

### Шаг 2: Создание емкостного датчика

**Вариант 1: Плоские электроды**

1. Вырежьте 2 пластины из нержавеющей стали (30x10мм)
2. Зачистите поверхность мелкой наждачной бумагой
3. Припайте провода к каждому электроду
4. Установите электроды параллельно на расстоянии 5-10мм
5. Используйте эпоксидную смолу для изоляции соединений
6. Оставьте рабочую часть электродов открытой (20мм)

**Вариант 2: Коаксиальная конструкция**

1. Найдите две трубки из нержавеющей стали (разного диаметра)
2. Вставьте меньшую трубку в большую с зазором 2-3мм
3. Используйте изолирующие прокладки для фиксации
4. Припайте провода к каждой трубке
5. Герметизируйте верхнюю часть

### Шаг 3: Подключение DS18B20

1. Если используете TO-92 версию:
   - Припайте резистор 4.7кΩ между VCC и DATA
   - Подключите провода согласно схеме
   - Изолируйте датчик термоусадкой или герметиком

2. Если используете водонепроницаемую версию:
   - Просто подключите провода к плате
   - Резистор уже встроен

### Шаг 4: Установка кнопок

1. Припайте кнопки к GPIO3 и GPIO4
2. Второй контакт кнопок - на GND
3. Можно использовать breadboard для прототипа

### Шаг 5: Сборка в корпус

**Рекомендуемая конфигурация:**

```
┌────────────────────────────┐
│  ┌──────────┐              │
│  │  OLED    │              │
│  └──────────┘              │
│                            │
│  [CAL]  [MEAS]  [PWR LED]  │
│                            │
│  ┌──────────────────────┐  │
│  │   ESP32-C3 Плата     │  │
│  └──────────────────────┘  │
│                            │
│  ┌──────────────────────┐  │
│  │   Аккумулятор (опц.) │  │
│  └──────────────────────┘  │
│                            │
│  [USB-C разъем]            │
└────────────────────────────┘
         │
         │ Кабель датчиков
         ▼
   ┌──────────┐
   │ DS18B20  │
   └──────────┘
   ┌──────────┐
   │Емкостный │
   │ датчик   │
   └──────────┘
```

## Питание

### Вариант 1: USB питание

- Подключите USB кабель к ESP32-C3
- Напряжение: 5V
- Потребление: ~150mA

### Вариант 2: Аккумулятор + зарядка

**Схема подключения:**

```
USB-C ──► TP4056 ──► Li-Ion ──► ESP32-C3
           (зарядка)  3.7V      (BAT pin)
```

**Компоненты:**
- Аккумулятор 18650 (3.7V, 2000mAh)
- Модуль TP4056 с защитой
- Выключатель питания

**Время работы:**
- 2000mAh / 150mA ≈ 13 часов непрерывной работы

## Калибровка датчиков

### Емкостный датчик

**Что понадобится:**
- Дистиллированная вода
- Чистый спирт (96-99%)
- Два чистых стакана

**Процесс:**
1. Промойте датчик дистиллированной водой
2. Погрузите в воду для калибровки 0%
3. Промойте и высушите
4. Погрузите в спирт для калибровки 100%

**Проверка точности:**
- Используйте известные растворы (40%, 70%)
- Сравните показания с эталоном
- При необходимости скорректируйте коэффициенты

### Температурный датчик

DS18B20 обычно не требует калибровки, но можно проверить:
1. Опустите в тающий лед: должно быть 0°C
2. Опустите в кипящую воду: должно быть 100°C (с учетом давления)

## Техническое обслуживание

### Очистка датчиков

**Емкостный датчик:**
- После каждого использования промывайте водой
- Раз в неделю: очистка спиртом
- При загрязнении: механическая чистка мягкой щеткой

**Температурный датчик:**
- Протирайте мягкой тканью
- Не используйте абразивные материалы

### Замена компонентов

**Признаки неисправности:**
- Датчик температуры: постоянное значение -127°C
- Емкостный датчик: значение всегда 0 или максимум
- Дисплей: нет изображения или артефакты

## Улучшения конструкции

### 1. Автоматическая очистка датчика
- Добавьте соленоидный клапан для промывки
- Используйте перистальтический насос

### 2. Защита от влаги
- IP65 корпус для электроники
- Герметичные вводы для кабелей

### 3. Термостабилизация
- Элемент Пельтье для поддержания постоянной температуры
- Улучшит точность измерений

### 4. Расширенный функционал
- Добавьте pH датчик
- Датчик мутности раствора
- Оптический датчик цвета

## Безопасность

⚠️ **ВАЖНО:**
- Не погружайте электронику в жидкость
- Используйте влагозащищенный корпус
- При работе с спиртом соблюдайте меры пожарной безопасности
- Не используйте поврежденные аккумуляторы
- Заряжайте только под присмотром
