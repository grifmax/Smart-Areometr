# План внедрения ADS1115 в проект Smart Areometr

## 📋 Обзор

Этот документ описывает полный план интеграции внешнего 16-битного АЦП ADS1115 для повышения точности измерений емкостного датчика.

## 🎯 Цели внедрения

1. **Повышение точности:** с ±0.5-1% до ±0.1-0.2%
2. **Улучшение стабильности:** с 70-85% до 90-98%
3. **Дифференциальный режим:** подавление синфазных помех
4. **Программируемое усиление:** для малых изменений сигнала
5. **Масштабируемость:** возможность добавления дополнительных датчиков

## 🔌 Схема подключения

### Физическое подключение

```
ESP32-C3              ADS1115 Module
─────────              ──────────────
GPIO5 (SDA) ──────────► SDA
GPIO6 (SCL) ──────────► SCL
3.3V       ──────────► VDD
GND        ──────────► GND
                        │
                        ├──► AIN0 ──► Электрод 1 (GPIO2 ранее)
                        └──► AIN1 ──► Электрод 2 (GND)
                        GND ────────► Общий провод
```

### Конфигурация I2C

- **Адрес ADS1115:** 0x48 (по умолчанию, можно изменить перемычками)
- **Частота I2C:** 100kHz (стандартная, можно увеличить до 400kHz)
- **Шина I2C:** Та же, что и для OLED дисплея (GPIO5/GPIO6)

### Настройки ADS1115

**Рекомендуемые параметры:**
- **Режим:** Дифференциальный (AIN0-AIN1)
- **Усиление (PGA):** 4× или 8× (для малых сигналов)
- **Скорость выборки:** 128 SPS (баланс скорость/шум)
- **Режим работы:** Однократное измерение (power-down между измерениями)

## ⚠️ Потенциальные проблемы и решения

### Проблема 1: Конфликт адресов I2C
**Решение:** ADS1115 имеет 4 возможных адреса (0x48-0x4B), OLED обычно 0x3C - конфликта нет.

### Проблема 2: Скорость I2C
**Решение:** Использовать стандартную частоту 100kHz, при необходимости увеличить до 400kHz.

### Проблема 3: Потребление энергии
**Решение:** Использовать режим power-down между измерениями, потребление ~150 мкА.

### Проблема 4: Обратная совместимость
**Решение:** Условная компиляция `#ifdef USE_ADS1115` позволяет использовать оба варианта.
