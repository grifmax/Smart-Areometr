# Smart Areometr - Электронный ареометр на ESP32-C3

Умный электронный ареометр для измерения содержания алкоголя в растворах на базе микроконтроллера ESP32-C3 с емкостным датчиком, температурной компенсацией и веб-интерфейсом.

## Возможности

- **Измерение алкоголя** в растворах (0-100%)
- **Температурная компенсация** результатов для точности
- **OLED дисплей** для отображения результатов
- **Веб-интерфейс** для удаленного мониторинга
- **Wi-Fi подключение** (режим клиента и точки доступа)
- **OTA обновления** прошивки по воздуху
- **Логирование измерений** с сохранением в файловую систему
- **Калибровка** для точных измерений (до 10 точек с интерполяцией)
- **MQTT интеграция** для умного дома (Home Assistant, Node-RED)
- **ADS1115 поддержка** - 16-битный внешний АЦП для повышенной точности
- **Автоматическое определение фракций** (головы, тело, хвосты)
- **Сессии дистилляции** с отслеживанием объема и статистикой
- **Мониторинг батареи** с индикацией заряда на дисплее и в веб-интерфейсе
- **Расширенное логирование** с графиками, фильтрами и статистикой
- **Управление приемниками** - автоматическое переключение приемников при смене фракций
- **Защита от переполнения** - автоматическое переключение при переполнении
- **Deep Sleep режим** - экономия энергии для батарейного питания
- **WebSocket** - real-time обновления данных
- **Многоязычность** - поддержка русского и английского языков
- **PDF экспорт** - экспорт отчетов и логов в PDF
- **Мультисенсорный режим** - поддержка до 4 датчиков через ADS1115
- **Веб-интерфейс для приемников** - страница receivers.html с графиками и управлением
- **Веб-интерфейс для датчиков** - страница sensors.html для визуализации всех датчиков

## Аппаратные требования

### Основные компоненты

1. **ESP32-C3 с OLED дисплеем** - [Плата на Ozon](https://ozon.ru/t/JTEZU4x)
   - Процессор: ESP32-C3 (RISC-V 160MHz)
   - Дисплей: OLED 0.42" (72x40)
   - Wi-Fi + Bluetooth 5.0
   - 4MB Flash

2. **Датчик температуры DS18B20**
   - Цифровой датчик температуры (OneWire)
   - Диапазон: -55°C до +125°C
   - Точность: ±0.5°C

3. **Емкостный датчик**
   - Используется встроенная функция touchRead() ESP32-C3 (базовый режим)
   - **ADS1115 модуль** (рекомендуется) - 16-битный внешний АЦП для повышенной точности
   - Электрод из нержавеющей стали
   - Измеряет диэлектрическую проницаемость раствора

4. **Кнопки управления** (опционально)
   - Кнопка калибровки
   - Кнопка измерения

### Схема подключения

```
ESP32-C3 Pinout:
├─ GPIO 8  → OLED SDA (I2C)
├─ GPIO 9  → OLED SCL (I2C)
├─ GPIO 2  → Емкостный датчик (Touch Pin)
├─ GPIO 10 → DS18B20 (OneWire) + резистор 4.7kΩ на VCC
├─ GPIO 3  → Кнопка калибровки (подтяжка к VCC)
└─ GPIO 4  → Кнопка измерения (подтяжка к VCC)
```

### Емкостный датчик

Для создания емкостного датчика:

1. Используйте два электрода из нержавеющей стали
2. Подключите один к GPIO2 (touch-capable pin)
3. Второй электрод - на GND
4. Расстояние между электродами: 5-10мм
5. Изолируйте соединения водонепроницаемым материалом

**Принцип работы:**
- Диэлектрическая проницаемость воды: ~80
- Диэлектрическая проницаемость этанола: ~24
- При изменении концентрации алкоголя меняется емкость датчика

## Установка и настройка

### 1. Установка PlatformIO

```bash
# Установка PlatformIO Core
pip install platformio

# Или используйте VS Code с расширением PlatformIO IDE
```

### 2. Клонирование репозитория

```bash
git clone https://github.com/yourusername/Smart-Areometr.git
cd Smart-Areometr
```

### 3. Сборка и загрузка

```bash
# Сборка проекта
pio run

# Загрузка на плату
pio run --target upload

# Загрузка файловой системы (веб-интерфейс)
pio run --target uploadfs

# Мониторинг серийного порта
```

**Важно:** Для работы веб-интерфейса необходимо загрузить файлы из папки `data/` в LittleFS!

Подробнее см. [data/README.md](data/README.md)

- **SSID:** `Areometr_AP`

Подключитесь к этой сети и откройте в браузере:
- **IP:** `192.168.4.1`

Для подключения к домашней сети измените в файле `src/main.cpp`:

## Использование

### Калибровка

Перед первым использованием необходима калибровка:

1. **Калибровка на воде (0% алкоголя)**
   - Погрузите датчик в чистую воду
   - Нажмите кнопку калибровки
   - Дождитесь сообщения "Water calibrated"

2. **Калибровка на спирте (100% алкоголя)**
   - Погрузите датчик в чистый спирт (96-99%)
   - Нажмите кнопку измерения для подтверждения
   - Дождитесь "Calibration done!"

Калибровочные данные автоматически сохраняются в памяти.

### Измерение

1. Погрузите датчик в измеряемый раствор
2. Нажмите кнопку измерения (или подождите автоматического измерения)
3. Результат отобразится на дисплее и в веб-интерфейсе

**Автоматические измерения:** каждые 5 секунд
**Температурная компенсация:** применяется автоматически

## Устранение неполадок

### Дисплей не работает
- Проверьте подключение I2C (SDA/SCL)
- Проверьте I2C адрес (по умолчанию 0x3C)
- Попробуйте использовать I2C сканер

### Некорректные измерения
- Выполните повторную калибровку
- Убедитесь, что датчик полностью погружен в раствор
- Проверьте температуру раствора (оптимально 15-25°C)
- Очистите электроды датчика

### Не подключается к Wi-Fi
- Проверьте SSID и пароль
- Убедитесь, что роутер работает на 2.4GHz (ESP32-C3 не поддерживает 5GHz)
- Попробуйте режим точки доступа

### Датчик температуры не найден
- Проверьте подключение DS18B20
- Убедитесь, что установлен подтягивающий резистор 4.7kΩ
- Проверьте правильность подключения (DATA, VCC, GND)

## Технические характеристики

- **Диапазон измерений:** 0-100% алкоголя
- **Точность:** ±2% (после калибровки)
- **Температурный диапазон:** 0-50°C
- **Время измерения:** ~1 секунда
- **Питание:** 5V USB или 3.7V Li-Ion аккумулятор
- **Потребление:** ~150mA в активном режиме

## Безопасность

**ВНИМАНИЕ:**
- Устройство предназначено только для измерения крепости растворов

- Не погружайте электронные компоненты в жидкость
