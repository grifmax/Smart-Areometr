📄 КАК ПОЛУЧИТЬ PDF:
═══════════════════════════════════════════════════════════════

🔹 СПОСОБ 1: Через браузер (САМЫЙ ПРОСТОЙ)
───────────────────────────────────────────────────────────────
1. Откройте файл BOM_and_Wiring.html в браузере
   (двойной клик или правой кнопкой → Открыть с помощью → Браузер)

2. Нажмите Ctrl+P (или Cmd+P на Mac)

3. Выберите "Сохранить как PDF" или "Microsoft Print to PDF"

4. Сохраните файл как BOM_and_Wiring.pdf

✅ ГОТОВО! PDF создан с красивым оформлением


🔹 СПОСОБ 2: Через pandoc (если установлен)
───────────────────────────────────────────────────────────────
Установка pandoc:
  Ubuntu/Debian:  sudo apt-get install pandoc texlive-xetex
  macOS:          brew install pandoc mactex
  Windows:        choco install pandoc miktex

Конвертация:
  ./convert_to_pdf.sh

или вручную:
  pandoc BOM_and_Wiring.md -o BOM_and_Wiring.pdf \
    --pdf-engine=xelatex \
    -V geometry:margin=2cm \
    --toc


🔹 СПОСОБ 3: Онлайн конвертация
───────────────────────────────────────────────────────────────
1. Откройте: https://www.markdowntopdf.com/
2. Загрузите файл BOM_and_Wiring.md
3. Скачайте готовый PDF


🔹 СПОСОБ 4: VSCode (если установлен)
───────────────────────────────────────────────────────────────
1. Откройте BOM_and_Wiring.md в VSCode
2. Установите расширение "Markdown PDF"
3. Ctrl+Shift+P → "Markdown PDF: Export (pdf)"

⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ:
═══════════════════════════════════════════════════════════════

1. ADS1115 НАСТОЯТЕЛЬНО РЕКОМЕНДУЕТСЯ!
   - Повышает точность в 4 раза
   - Стабильность измерений 90-98% vs 70-85%
   - Стоит всего ~150-200₽, но дает огромный прирост качества

2. При работе с приемниками:
   - Диоды 1N4007 обязательны для защиты
   - Проверьте полярность перед включением
   - Используйте отдельный БП 12V для клапанов

3. Батарея:
   - Используйте только Li-Ion с защитой
   - TP4056 должен иметь защитную микросхему DW01A
   - Не заряжайте без присмотра

4. Безопасность:
   - Работа со спиртом - пожароопасна!
   - Не погружайте электронику в жидкость
   - Используйте водонепроницаемый корпус
